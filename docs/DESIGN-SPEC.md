## 0. 速览：这套界面长什么样

一句话：**贴在屏幕边缘的一张会呼吸的深色小卡片**，点开变成完整倒计时卡；所有界面共用当前主题的「深色垂直渐变 + 单一强调色 + 极淡描边 + 大圆角 + 不画投影」；设置窗口是独立的浅色系统（不跟主题换色）。

| 界面 | 关键数字 | 跟随主题? | 一句话 |
|---|---|---|---|
| 收起卡 | 224×68 DIP，圆角 14 | 是 | 状态点 + 左标签 + 右槽 + 大号倒计时 + 3 DIP 进度条 |
| 展开卡 | 280×164 / 188（有午休行），圆角 18 | 是 | 7 行等距，行距 6，右上 5 图标 |
| 工资面板 | 展开卡 +116 DIP | 是 | 今日收入 22pt 渐变数字 + 本月收入 + 发薪日 |
| 卡内提醒 | 尺寸不变，色块覆盖 | 是（4 类各一配色） | 两块色块叠上来，文字后浮入 |
| 全屏提醒 | 覆盖卡片所在屏 | 是（警戒带除外） | 圆/条扩散铺满屏；或工业黄警戒带 + 抽屉卡 |
| 小纸条 | 392×282 / 476 / 124 / 158；双栏 470×298 / 512 | 是 | 1.8 DIP 主题色边框，圆角 18，无投影 |
| 右键胶囊 | 胶囊 124×40；长开面板 246 宽 | 是 | 6 颗竖排，点开原地长成面板 |
| 设置窗口 | 690×640 DIP（左栏 148 + 内容 542） | 否（固定浅色） | 左栏 7 页 + 右侧白卡 + 底部保存 |
| 首次引导 | 470×470 | 否（固定浅色） | 三段式表单 + 开始用/先跳过 |

**两套并行设计语言**（重要，别混）：

1. **悬浮层**（卡片 / 小纸条 / 胶囊 / 抽屉 / 提醒）：底色永远来自当前主题（`bgTop→bgBottom` 90° 垂直渐变），文字/描边/高光全部由主题派生，**无系统边框、无投影、逐像素 alpha 分层窗**。
2. **设置层**（设置窗口 / 首次引导 / 各种对话框）：固定浅色（`#F6F8FB` 底 + 白卡 + `#407CF5` 蓝），**不跟随主题**；窗口跟着系统 DPI 整体缩放。

## 1. 设计原则与品牌调性

| 原则 | 具体表现（可验收） |
|---|---|
| **贴边、低打扰** | 默认收起成 224×68 的横条贴在屏幕右缘；展开 20 秒无操作自动收回（可关）；提醒才主动铺开。桌面原样可见：全屏提醒「条外一个像素都不画」。 |
| **信息优先，一屏一句** | 收起态只有「状态点 + 一句话 + 倒计时 + 右槽 + 进度条」；展开态 7 行全部是结论（距离下班 / 上班时间 / 预计下班 / 已工作 / 应勤），不放大段说明。 |
| **数字是主角** | 倒计时 28pt 等宽（收起 17pt、工资 22pt），中文说明压在 9–9.5pt；字重只有 Regular/Bold 两档。 |
| **一屏一个饱和色** | 除状态点、进度条、强调按钮、提醒色块外，其余是主题的 3 级灰阶；语义色（成功绿 / 琥珀 / 提醒类别色）只出现在状态点、提醒和错误提示。 |
| **圆角大、边框极淡、不画投影** | 卡片 14/18、胶囊全圆角 20、纸条 18；卡片描边是 `accent @ 24/255`（≈9.4%），纸条 `accent @62%` 1.8 DIP；所有悬浮层**不画投影**，靠一条细边贴住桌面。 |
| **渐变方向统一** | 卡片、主题缩略图、纸条、胶囊全部「上→下」90° 垂直渐变；磨砂玻璃只是同一渐变的半透明雾面版。 |
| **动效短而软** | 150–430ms、easeOutCubic / cubic-bezier(.22,.9,.28,1)，淡入 + 轻微位移（6–14 DIP），没有弹跳；「减少动态效果 / 高对比度」下只保留最终帧。 |
| **克制的中文排版** | 中文苹方 → Noto Sans SC → 微软雅黑（可放 `fonts\` 私有字体）；数字 Consolas；小字灰阶抗锯齿 + 整数像素定位，不用 ClearType（透明底会镶彩边）。 |

品牌语气：**「班」字方块 + 工具感**。设置窗口左上角一枚 accent 色 20×20 圆角方块，内写白色「班」；产品名固定「上班工具箱」；图标是 12–14 DIP 的细线几何图标，不用彩色插画、不用 emoji。

## 2. 设计令牌

### 2.1 颜色令牌（主题 9 色键）

`ThemeDef`（`src/Models.cs`）里有 **9 个颜色键** + 元数据（`id` / `name` / `author` / `description` / `created` / `filePath` / `isUser`）。有的旧文档写「10 色键」，那是把 `id`/`name` 也算进去了；**渲染实际只用 9 个颜色**。

| 键 | 类型 | 语义 | 被谁直接用 |
|---|---|---|---|
| `accent` | Color | 强调色：状态点、进度条已走段、右上图标激活、选中边框、发送按钮、大数字渐变 | 全部界面 |
| `success` | Color | 成功色：「已达标 / 已下班」状态点、发薪日 ≤3 天、「已经是最新版本」 | 卡片 / 设置页 / 胶囊 |
| `bgTop` | Color | 卡片渐变上端；**也是「是否浅色」的判定输入**（`Luminance(bgTop) > 0.56`） | 全部悬浮层 |
| `bgBottom` | Color | 卡片渐变下端；卡片「次/弱文字」混色的基色 | 全部悬浮层 |
| `track` | Color | 进度条轨道 | 卡片进度条 |
| `textMain` | Color | 主文字 / 大数字（默认） | 全部界面 |
| `textMuted` | Color | 次文字；**只有右键胶囊/设置页列表直接取**，卡片和纸条是现算的 | 胶囊 / 设置 |
| `textDim` | Color | 弱文字；同上 | 胶囊 / 设置 |
| `edge` | Color | 极淡描边（**带 alpha**）：内置深色 `#0AFFFFFF`（白 3.9%）、内置浅色 `#1E182030`（11.8% 墨）、用户主题按文件值（深 `#16FFFFFF`、浅 `#1E000000` 是自建配色规则） | 纸条 / 胶囊细边 / 列表行边 |

深浅主题的判定：**不是字段，是派生** —— `Luminance(bgTop) > 0.56` 判为浅色（`0.2126R + 0.7152G + 0.0722B`）。浅色主题：文字用深色、卡片光照压暗；深色主题反之。

主题来源（v5.0 起）：

- **内置 39 套**（`Themes.BuiltIn`，`Models.cs:BuildAll`）；
- **用户主题文件**（`themes\*.theme.json`，`ThemeFiles.LoadAll()`，见第 6 节）；
- `Themes.All` = 39 内置 + 用户主题（用户主题永远排在最后，按文件名排序）；
- 当前选中的主题 id 存在 `settings.json` 的 `ui.theme`；**未知 id（主题文件被删 / 老配置）回退 `midnight`**（`Themes.FallbackId = "midnight"`，`Normalize` 里执行）。

### 2.7 磨砂玻璃（Frost）令牌

`ui.bgStyle = glass` 时，卡片 / 小纸条 / 胶囊三处一起换成 `Frost.PaintSurface`（拟态，不是真实抓屏模糊）：

| 元素 | 参数（源码 `Frost.cs`） |
|---|---|
| 半透明主题底 | 深色主题基准 alpha **206**、浅色 **218**；顶端 `bgTop`（深色 ×0.97）、底端 `bgBottom`（×0.93），90° 渐变 |
| 两团柔光雾 | 左上 accent 雾 `alpha 76/96 × k`、右下 accent 雾 `alpha 38/30 × k`（k 为 DPI 缩放）；`PathGradientBrush` 中心亮点 |
| 磨砂颗粒 | 128×128 tile、2×2 块噪点 + 盒式模糊，低 alpha 叠加 |
| 斜向反光带 | 白色斜向渐变（顶部 0 → 中 26/18 → 0），`PaintSheen` |
| 玻璃边缘 | 顶部高光 白 `alpha 190/150`、底部暗边 黑 `alpha 46/56`，1 DIP 圆角描边 |

> 磨砂是「半透明 + 柔光 + 颗粒 + 反光」的拟态；桌面会透出来，但不是逐像素模糊。想要更透/更实就换主题（深色玻璃更暗、浅色更亮）或换回纯色。

- **重播**：常驻下班提醒每 5 分钟重播一次文字淡出→淡入（1100ms），卡片本身不闪。
- **减少动态 / 高对比度**：跳过色块与文字动画，直接画最终帧。

### 3.5 全屏提醒（圆形 / 进度条 / 警戒带）

全屏提醒是**另一个铺满「卡片所在屏」的分层窗**（`ScreenReminderForm`），设计坐标 **1280×720**，实际按 `layout = min(屏宽/1280, 屏高/720)`（≥0.5）缩放。底图是开始时的桌面截图；条外/色块外不画像素，桌面原样可见。

**圆形 / 进度条扩散**：

- 起点 = 进度条已走段的末端（收起条 y=59+1.5，展开条 y=102+2；`tipX` 按 progress 算）。
- 圆形：半径从 0 扩到「屏角最远距离 + 40」，柔边 `clamp(10, 90, r×0.07)`，100ms 起 500ms 完成。
- 进度条：先横向拉满（100–380ms），再纵向撑开（360–620ms），共用一条左→右擦线。
- 铺满后内容擦出：`reveal` 在圆形 600ms / 条 650ms 起、320ms 完成；标题 46pt×layout、类型 12pt、剩余 19pt、时间 28pt、地点 16pt、备注 14pt、提示 11.5pt。
- 停留 = `min(6000, max(3000, reminderHoldSeconds×1000))`，退场 760ms 收回（色块 260ms 起 420ms 缩回，文字 240ms 先收）。
- 点任意处 / Esc 立即收回；提醒本体继续按常驻规则留在卡片上。

```
┌──────────────────────────────────────────────────────────────┐
│ ⚠ 会议提醒                                                   │  类型 12pt（62% 墨）
│ 产品评审会 · Q4 排期                                         │  标题 46pt
│ 10:30–11:00 · 3F 云杉会议室                                  │  时间/地点/备注
│ [还剩 10 分钟]                                        [×]    │  剩余 19pt / 关闭
│                                          点任意处关闭          │  11.5pt（45% 墨）
└──────────────────────────────────────────────────────────────┘
```

**警戒带（tape）**——第三种全屏样式，只在 `reminderSpread=screen && reminderSpreadStyle=tape` 时走：

- 条：整屏宽、**高 60 DIP**、垂直居中；上下各 **8 DIP** 黄黑斜纹；斜纹单条厚 14 DIP、水平周期 39.6 DIP、速度 100 DIP/s 向右；文字 70 DIP/s 向左。
- 内容 = `⚠ 15 DIP + 类型（10.5px Bold）+ 分隔点 + 标题（16.5pt Bold）`，两条之间空隙 **35 DIP**，整段重复铺满。
- 呼吸：底色黄 `#F5C400` 的 alpha 从 1 → 0 → 1，**2.33s** 一轮；文字颜色在黑 `rgb(11,12,14)` 与黄 `rgb(255,216,77)` 之间插值；快透明时加一层黑影保证浅色壁纸可读。
- 帧率：警戒带 8ms/帧（配合 `timeBeginPeriod(1)`），普通全屏提醒 33ms/帧。
- 降级：减少动态 / 高对比度 → 不弹全屏，直接显示卡片提醒（警戒带同样）。
- 警戒带**卡片不做色块覆盖**，信息交给黄条 + 之后的抽屉卡（见 3.6）。

## 5. 状态与动效

### 5.1 状态矩阵（卡片文案）

| 状态 | headline | bigLabel | 大数字 | sub（第 5 行） | 午休行 | 脚注 | 状态点 |
|---|---|---|---|---|---|---|---|
| 工作中 | `工作中` | `距离下班` | `HH:mm:ss` | `上班 09:27 · 预计下班 18:00` | 距午休/距晚休 + 时长 | `已工作 5h31m · 应勤 9h00m` | accent |
| 未上班 | `未上班` | `距离上班` | 距上班时长 | `上班时间 09:00 · 周五` | 可有 | `飞书里发「1」即完成上班打卡` / `未接入飞书，按班次时间计算` | accent |
| 还没打卡 | `还没打卡` | `上班已过` | 已过时长 | 同未上班 | 可有 | 飞书相关提示 | **`#F2B34C`** |
| 已达标 | `已达标` | `可下班 · 已超` | 超时时长 | 上班/预计下班 | 照常 | `在岗 5h31m · 下班后发「2」记录` | **success** |
| 已下班 | `已下班` | `今日在岗` | 在岗时长 | `09:27 → 18:40` | 无 | `工时已达标 · 应勤 9h00m` / `工时 x / 应勤 y` | **success** |
| 休息日 | `休息日` | `周五` 等 | `今天休息`（17pt） | `下次上班 11月17日 09:00（周一）` | 无 | `右键可临时设为上班日` | accent |

- 午休行细节：`距午休 1h30m` → `午休中  还剩 1h05m`（计数中颜色变主文字）→ `距晚休 4h30m` → `晚休中  还剩 35m` → `马上下班`；没开晚休时午休后改 `距下班 x`；整行 9.5pt Bold。
- 大数字格式：剩余 <60 分钟 → `mm:ss.厘秒`（如 `03:12.45`，每 55ms 重绘看到跳动）；≥60 分钟 → `HH:mm:ss`（总小时，>99 变 3 位）。
- 收起态右槽：`下班 19:30`；午休/晚休计数时 `休 1h05m` / `晚 45m`。
- 未接入飞书时按班次推算，不出现「还没打卡」。

### 5.2 展开 / 收起时间轴

| 时刻 | 事件 |
|---|---|
| 0ms | 单击收起条；窗口开始 150ms 尺寸补间（宽 224→280、高 68→164/188） |
| 0ms | 大数字 + 进度条（主视觉）最先开始淡入（公式里提前 40ms），上移 8 DIP |
| ≈15ms | 状态行开始淡入（6 DIP 上移） |
| ≈70ms | 说明行 |
| ≈125ms | 下一段 |
| ≈180ms | 午休行 |
| ≈235ms | 脚注 |
| 每行 | 190ms 淡入；同一行元素共用一条时间线（`p[i] = clamp((flow+40−i×55)/190)`，共 6 行） |
| ≈530ms | 最后一行落定（`StaggerTotalMs = 6×55+200`） |
| 20s 无操作 | 自动收回（可配 0–120s；0 = 不自动） |

收起反向：窗口 150ms 缩回，文字随尺寸收掉（不单独做退场）。工资面板另走 430/300ms（见 3.3）。

### 5.3 提醒入场 / 退场时间轴

**卡内普通提醒**（`PaintCardReminder`）：

| 时刻 | 事件 |
|---|---|
| 0–300ms | A 色块（整卡）从上方落定（easeOutCubic，位移 `-seam`） |
| 260–660ms | B 色块（下段）从下方顶上来（easeOutCubic） |
| 470ms 起 300ms | 标题/文字淡入并上浮 7 DIP（`contentA`） |
| 停留 | `max(3–20s, 时段剩余)`，常驻期间「还剩 N 分钟」每秒更新 |
| 退场开始 | 文字 150ms 淡出 |
| 退场 | B 先走（+130ms 起 280ms），A 后走（+330ms 起 280ms）；总 960ms 窗口 |
| 减少动态 / 高对比度 | 直接画最终提醒帧 |

**全屏普通提醒**：入场 1000ms（扩散 → 擦出）；停留 3–6s；退场 760ms。

**警戒带**：卡片先展开 **400ms** → 黄条入场（文字/斜纹持续滚，呼吸 2.33s）→ 黄条放完卡片收回 **400ms** → 等 **0.3s** → 抽屉卡 550ms 拉出；抽屉留到日程结束，点一下收回。

**常驻下班提醒**：第一遍同普通提醒；之后每 **5 分钟**重播一次文字淡出→淡入（1100ms，卡片本身不闪）；同步到下班打卡 / 跨天 / 点 × 时收掉。

### 5.4 未读角闪（v3.8.1 起）

- **收到纸条**：`noteFlashAt = now` → 整圈贴边闪光 **1300ms** 关键帧：`RimT{0,.08,.24,.40,.60,.75,.90,1}` / `RimA{0,.95,.12,.90,.10,.50,0,0}`（峰值 0.95@104ms、0.90@520ms、0.50@975ms）。
- **未读期间**：`tick`（1s）调用 `MaybeBlinkUnread()`，每 **5000ms** 触发一次；`flowT`（55ms）在 `NoteRimActive()` 为真时持续重画。
- **包络** `CornerFlashAlpha(elapsed)`：0–150ms 第一下、250–400ms 第二下，`sin(u·π)` 快进快出；总 **420ms**。暗隙 150–250ms、400ms 后熄灭。
- **画法**（`DrawNoteCorner`）：裁到卡片圆角内；起点 inset 1 DIP、圆角 r=13（收起）/17（展开）、顶部/左侧各延伸 `min(20, W×0.14)` ≈20 DIP；4 趟描边（alpha `a·26/i`，线宽 max(2, 2i)）+ accent 芯（2.2 DIP，alpha `a·235`）+ 白高光（1 DIP，alpha `a·140`）；角上一团 `64×64` 柔光（中心 `(2,2)`，alpha `0.40a`）。
- **静默**：`reducedMotion || HighContrast` → 0 且不调度；未读归 0 即停。
- 收起态 / 展开态都画；**收起态没有常驻未读角标**（只有闪），这是当前已知限制（见 10）。

### 5.5 流光与进度

- 进度条流光 2.6s 一圈；带从「已走段左端」走到「右端」；两端淡入/淡出；`filled > 4h` 才画；减少动态/高对比度不画。
- 卡外流光层：呼吸 4.2s、扫边 5.5s；减少动态/高对比度时**不创建**该窗口。
- 卡片背景光效 A/B 是静态叠色（强度 1.6×），不跑动画。

### 5.6 工资数字

- 18fps（55ms）重算：今日收入 = 时薪 × 已工作秒数，上限日薪；后 3 位小数每帧 +≈0.003。
- 整数位：主题 accent 渐变（深→亮 10°）+ 8 方向 × 2 圈柔光（半径 2/4 DIP，alpha 18/8）+ 6.5s 一轮白色流动高光（峰值 alpha 150）；浅色主题：压深、柔光 10/4、流光 alpha 80。
- 小数位：`textMain`。
- 面板收起时停止刷新（`flowT` 只在 `salaryOpen` 或相机闪烁时继续）。

### 5.7 胶囊菜单动效

见 3.8 与 2.8。补充：点击动作**等淡出/收回完成后再执行**（避免设置窗、调色盘被菜单压住）；长开时下面的胶囊被顶下去，内容 35%→80% 淡入。

### 5.8 小纸条动效

- 打开：300ms 淡入 + 从卡片方向滑入 14 DIP；关闭 180ms；长高 320ms easeOutCubic。
- 发送：旧消息上移、新消息从底部进入，只动两行，不整块刷新；不显示「已发出」。
- 历史：新行 240ms 浮入；历史页整体重绘动画至少 760ms（保证最后一行完整淡入）。
- 编辑窗（改名字/输入框上的小窗）：非模态、圆角、和输入框同宽；焦点。减少动态时全部直接到位。

### 5.9 降级（减少动态效果 / 高对比度）

| 能力 | 减少动态（`ui.reducedMotion`） | 高对比度（系统） |
|---|---|---|
| 展开错峰 / 行浮现 | 跳过，直接终帧 | 同 |
| 提醒扩散 / 擦出 | 跳过，直接画提醒帧 | 同 |
| 全屏提醒 / 警戒带 | **不弹全屏**，显示卡片提醒 | 同 |
| 抽屉卡 | 直接到位 | 同 |
| 进度条流光 | 不画 | 不画 |
| 未读角闪 / 收闪 | 不闪（收到整圈闪的绘制不看该开关，但 flowT 只在 `NoteRimActive` 时帧；实际肉眼不可见） | 角闪为 0 |
| 卡外流光层 | 不创建（运行中切换不销毁） | 不创建 |
| 工资数字 | 仍刷新（金额信息必要） | 同 |
| 折叠/展开 | 150ms 保留（尺寸补间不判开关） | 同 |

## 6. 主题系统

### 6.1 结构

- **内置 39 套**：编在 `Models.cs`（`Themes.BuiltIn`），不可改、不可删、可导出。
- **用户主题**：一个主题一个文件，`themes\*.theme.json`；v5.0 起 **settings.json 的 `customThemes` 不再是真源**，只在首次加载时一次性迁移成文件后清空。`Themes.SetCustom` / `Themes.IsCustom` 已删除，`SettingsApplyPlan` 不再比较 `customThemes`（主题文件不参与配置 diff）。
- **注册表**：`Themes.All = 39 内置 + ThemeFiles.LoadAll()`（用户主题按文件名排序，同 id 只认第一个）；`Themes.Reload()` 在启动 / 导入配置后重扫目录。
- **当前选中**：`ui.theme`（id）。主题文件被删 / id 不存在 → 下次 `Normalize` 回退 `midnight`（`Themes.FallbackId`）。
- **设置页影响面**：背景风格（纯色/磨砂玻璃）、背景光效、字体都是独立设置，不随主题变；主题只决定颜色。
- **v5.0 删除项**：`src/Skins.cs`、`SkinPicker`、`SkinProgress`、`UiSettings.skin` 字段；旧配置 `"skin"` 字段被忽略、不迁移不报错；`AppInfo.Version` = 5.0.0。

### 6.2 主题文件格式（schema=1）

**目录**：

| 模式 | 路径 |
|---|---|
| 正常 | `%APPDATA%\WorkCountdown\themes\`（`SettingsStore.Dir` + `themes`） |
| 便携 | `exe\data\themes\`（`portable.txt` / `--portable` 时 `SettingsStore.Dir` 指向 `data\`） |

**文件名**：`<id 的 slug>.theme.json`；slug 保留字母数字（含中文）和 `-` `_`，其它字符换成 `-`，最长 40 字符。

**完整示例**：

```json
{
  "schema": 1,
  "app": "WorkCountdown",
  "id": "my-night-owl",
  "name": "我的主题 · 夜航",
  "author": "张三",
  "description": "深夜办公用的低饱和蓝",
  "created": "2026-11-17 20:00:00",
  "colors": {
    "accent": "#4C8DFF",
    "success": "#46D39A",
    "bgTop": "#12161F",
    "bgBottom": "#1B2130",
    "track": "#2A3242",
    "textMain": "#E8EDF7",
    "textMuted": "#8B95A8",
    "textDim": "#6C768A",
    "edge": "#0AFFFFFF"
  }
}
```

**字段规范**：

| 字段 | 必填 | 说明 |
|---|---|---|
| `schema` | **是** | 整数，当前只认 **1**；不认识 → 整文件跳过（提示「不支持的主题文件版本：N」） |
| `app` | **是** | 必须等于 `WorkCountdown`（防止误导入别人的 `.theme.json`） |
| `id` | **是** | 去空白后非空；导入时与内置/已有主题撞 id → 自动加 `-2` / `-3` |
| `name` | **是** | 去空白后非空；设置页显示名 |
| `author` | 否 | 缺省 `""` |
| `description` | 否 | 缺省 `""`；迁移主题写「从 v4 旧配置迁移」 |
| `created` | 否 | `yyyy-MM-dd HH:mm:ss`；缺省写当前时间 |
| `colors` | **是** | 必须含全部 **9 个键**；任何一个缺/坏 → 整文件跳过（不做字段级回退） |

**颜色格式**：`#RRGGBB` 或 `#AARRGGBB`（大小写都认，前后空白忽略）；`edge` 的 alpha 要原样写（深色内置 `#0AFFFFFF`、浅色内置 `#1E182030`）；`ColorText` 输出时 alpha=255 写 6 位、否则写 8 位。

**其它**：UTF-8（带不带 BOM 都能读）；写入用「临时文件 + 原子替换」（FAT / U 盘不支持时退化为删除+改名）；未知字段忽略；同 id 多文件只认文件名排序第一份；坏文件 **跳过并返回中文 error（扫描 `LoadAll` 阶段静默跳过、不写日志；导入时 UI 直接显示 error）**，不影响内置 39 套和其它合法主题。

### 6.3 导入 / 导出 / 删除

| 动作 | 规则 | 失败/反馈语义 |
|---|---|---|
| **导入**（按钮「导入主题…」） | 文件选择器接受 `*.theme.json;*.json`（也可选所有文件）→ 校验（schema/app/id/name/colors 全过）→ 重新排版成标准文件复制进主题目录；id 冲突自动后缀；`created` 缺省补当前；成功后 `Themes.Reload()` + 预览并切到该主题，弹「已导入主题「X」，点「保存」后生效。」（`ui.theme` 要保存才落盘） | 校验失败弹「主题没有导入成功：\n{中文原因}」，不落盘 |
| **导出**（按钮「导出当前」） | 任意主题（含内置）→ 保存对话框 `*.theme.json`，默认文件名 `<主题名>.theme.json`；路径无扩展名时自动补 `.theme.json`；不修改传入对象；内置也能导出给别人 | 成功「已导出到：{path}」；失败「主题没有导出成功：\n{原因}」 |
| **删除**（按钮「删除」） | 只对**用户主题**可用；确认「删除用户主题「X」？文件会一起删掉。」→ `ThemeFiles.TryDelete` 删文件 → Reload；若删的是当前主题，草稿 `ui.theme` 回退 `midnight` 并预览（点保存才落盘） | 内置主题点删除：弹「内置主题不能删除。」；删除失败弹原因 |
| **保存（新建/编辑）** | 新建用户主题：名字 → 新 id（`my-<slug>`，冲突加后缀）→ 写文件；编辑：改名字/颜色后覆写原文件 | 同写盘失败 |

设置页入口在「外观 → 主题配色」卡（色卡下方一行 5 个按钮：`＋ 新建主题` / `编辑` / `导入主题…` / `导出当前` / `删除`；编辑、删除仅用户主题可用；见 3.9）。

### 6.4 旧配置迁移（settings.json → 主题文件）

- 触发时机：**启动加载配置（`SettingsStore.Load`）与导入配置（`SettingsStore.Import`）**；不再有「保存时迁移」。流程 = 反序列化 → `MigrateThemes()`（先 `NormalizeCustomThemes` 做兼容清理，再 `ThemeFiles.MigrateLegacy`）→ `Themes.Reload()` → `Normalize()` → 比较后落盘。
- 规则：每个旧 `customThemes[]` 条目 → 一个主题文件；最老只有主色的按 `FromAccent` 推导，v3.3+ 有背景色/进度条色的按 `FromColors`；`description = "从 v4 旧配置迁移"`。
- **幂等**：同 id 已有文件（内容 id 相同）→ 跳过；文件名被别的 id 占用 → 换 id 后缀；与内置/已有主题撞 id → 换 id。
- **清空策略**：只有 `failed == 0`（全部成功，含已迁移）才 `customThemes.Clear()`；有失败则保留旧列表，下次加载再试（不丢用户主题）。迁移成功后 `settings.json` 不再写 `customThemes`（字段保留只为迁移）。
- `WC_NO_SAVE=1`（探针）下迁移照写主题文件（主题文件是独立数据，不属于配置快照；幂等），但配置快照本身不落盘。
- 迁移本身也是「写文件 + 原子替换」；单个旧主题写失败只计数，不中断启动。

### 6.5 回退与非法值

| 情况 | 行为 |
|---|---|
| 主题文件坏 / schema 不认识 / app 不对 / 缺键 / 颜色格式错 | 该文件跳过（`LoadAll` 忽略，不抛异常）；不影响其它主题 |
| `ui.theme` 指向不存在的 id | `Normalize` 回退 `midnight`（`Themes.FallbackId`） |
| 同 id 多个文件 | 按文件名排序，只认第一个 |
| 主题目录不存在 | `LoadAll` 返回空列表；导入/保存时自动创建 |
| 颜色缺 alpha | 6 位视为不透明（alpha=255） |

### 6.6 自建 / 编辑主题（调色窗）

- 两个色块：**背景**（决定 bgTop/bgBottom/track/文字明暗）与**进度条**（决定 accent）；切换按钮「背景」「进度条」。
- 色相条选颜色家族、SV 方块选深浅；右侧实时预览「这个背景 + 这个进度条」的小卡片；名字输入 ≤ 随便（空则「我的主题」）。
- 保存后：新建写文件并立刻切到新主题；编辑覆写原文件。
- 内置主题不能直接改（「编辑」置灰）；「＋ 新建主题」会把当前主题的配色作为起点。

## 10. 已知限制与后续改进

### 10.1 已确认的界面限制

1. **收起态没有常驻未读标记**：只有「每 5 秒闪两下」；未读数量本身在收起态不可见。加常驻标记需重做左上角布局（见 `design/note-notify-spec.md`）。
2. **分层窗口圆角有 1 像素台阶**：靠近看能看到 1px 台阶；`Region` 裁剪会硬锯齿，因此没有退回去用 Region。
3. **磨砂玻璃是拟态不是真实模糊**：真实抓屏模糊在秒/厘秒刷新时掉帧，且分层窗会把自己拍进去。
4. **多屏混合 DPI 会被系统拉伸**：只做系统级 DPI 感知，没有逐显示器 DPI 适配（`DpiChanged` 未处理）。
5. **设置窗口内容区需要滚动**：外观页三张卡底到 **592**、纸条页到 570，都超过内容区 546；靠滚轮/滚动条看最后一张卡的底部。
6. **主题色卡没有滚动条、行数多了会变矮**：色卡行数 = `ceil(Themes.All.Length/10)`，但绘制被限制在 122 DIP 高内，用户主题超过 40 套后每格变矮、行数继续增加会挤在一起；没有独立滚动（整页滚动交给 contentHost）。
7. **主题色卡与固定日程列表的间距按物理像素画**：150% 下色卡 gap 仍是 6px（=4 DIP）、圆角 5px，和其它 DIP 元素比例略不一致（历史实现；不影响功能）。
8. **设置→工资→怎么算 第 6 条是陈旧文案**：「双击固定在展开状态」v3.2 已取消，实际只有单击展开/收起；删除这条或改为「单击展开 / 收起」即可。
9. **设置→纸条→删除对话确认文案写「最多 8 条消息」**：实际每对话最多 16 条（`NoteSettings.MaxMessages`），文案已过期。
9. **卡片内「该下班啦」的配色语义**：默认取「松林绿」折算，是清爽绿不是警示红；如果用户把「下班」配色改成红色系，会变成红色提醒——这是配置自由度，不是 bug。
10. **提醒只在程序运行时触发**：关机/未启动不补提醒；启动时若仍在提醒窗口内会再放一次。
11. **全屏提醒只覆盖卡片所在屏**：多屏时另一块屏不显示。
12. **未读整圈闪不判 reducedMotion**（`DrawNoteRim` 绘制不看开关，只靠 flowT 的静默分支）；角闪判。改这里要同步 `NoteRimActive()`。
13. **图标/文字颜色相对主题色是硬编码 alpha**：主题极暗或极亮时个别描边（accent@24）可能几乎不可见；`edge` 有 alpha，深浅主题分别取值。
14. **胶囊长开面板高度固定**：内容超出（如更新记录很长）靠内部滚动，不随内容长高。
15. **设置窗口跟随系统主题**：`FixedDialog` 标题栏走 Windows 主题（浅色/深色由系统决定），不跟应用主题。
16. **色卡不识别人气/排序**：用户主题按文件名排序排在最后，用户不能拖拽排序；当前主题被删后回退 midnight，不会提示「主题文件已删除」。

### 10.3 后续可改进项（按性价比排序）

1. 收起态未读常驻标记（静态角标/折角信），并同步 `NoteRimActive()` 与 reducedMotion 替代。
2. 删除/修正设置页两处陈旧文案（工资「双击固定」、纸条「最多 8 条」）。
3. 让主题色卡/日程列表也走 `S()`，修 150% 下比例不一致。
4. 设置窗口测试模式下可选「内容区自适应高度」（减少滚动）。
5. 用户主题在色卡里加「我的」角标 / 名字 tooltip，解决「用户主题与内置同格不可区分」。
6. 逐显示器 DPI 适配（`DpiChanged` + 重算字体/几何）。
7. 未读角闪可配置（开关 / 间隔 / 样式），目前写死 5s 两下。
8. 胶囊长开面板内容超长时改为面板长高 + 内部滚动，而不是只有内部滚动。
