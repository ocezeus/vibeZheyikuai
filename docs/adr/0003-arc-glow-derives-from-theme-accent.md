# 弧光的光色由主题强调色派生，不再单独挑一套色板

卡片内的「弧光」要在 39 套主题、纯色与磨砂玻璃两种背景风格下都成立。若为它另配一套固定色板，每套主题都得回答一次「弧光和这套主题配不配」，并出现第二个需要手动维护的颜色来源。

决定以当前主题的强调色作种子，按固定色相偏移派生出全部光色：−45° 近邻色、0° 种子色（亮度提到 64%）、−100° 环境色、+42° 另一侧邻色，另有近白高光与深色底光；饱和度统一抬到 68% 下限，保证偏灰的强调色也能发光。派生是纯函数并按强调色缓存，换主题只换种子，不新增任何手选入口。卡片底色、文字与进度条仍取该主题自己的定义，弧光不参与重做主题。

可用性只看《默认》界面风格；纯色与磨砂玻璃只是卡片底的画法，不影响能不能开。其它皮肤不画弧光，但保留用户存下的开关值，切回默认即恢复。开启后是否重画取决于现有的 18fps 重画节拍，「减少动态效果」时弧光静止且不触发重画。

代价是 GDI+ 没有 CSS 的 screen 混合与真实高斯模糊，观感靠半透明叠加与缩小再放大的近似模糊，浅色主题还要先把光色压深一档；因此最终强度以实拍与像素分位数标定，而不是照搬原型里的 alpha 值。
