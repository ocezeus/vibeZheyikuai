# 以兼容配置格式和有效快照承接渐进重构

现有程序的文件名、配置目录和配置内容承载旧安装、历史工作日迁移、小纸条历史及多日历缓存；重构时直接改名或替换配置格式会使这些数据与入口失效。决定保留 WorkCountdown.exe、既有安装与配置路径、便携模式、既有字段及迁移语义，把迁移和规范化知识集中在配置模块；保存接口必须区分成功、失败与只读跳过，正式写入采用同目录临时文件及原子提交，失败不得破坏上一份有效配置。

配置应用按受影响范围生效；后台任务使用隔离的配置快照，并在提交结果前检查所属配置代次和模块生命周期，过期结果不得更改当前日程、缓存、凭据或持久化数据。相较共享可变配置并允许请求任意回写，这会增加快照复制及结果合并的实现成本，但能明确数据所有权并防止旧连接结果覆盖新设置；成功、部分失败与仍可使用的历史缓存必须分别表达，用户编辑保存失败应得到可见反馈。

本记录是已采纳的目标设计，现有实现仍需后续工单迁移。暂不迁移数据库、安装布局或桌面框架；新增结果类型和内部模块归属可在保持上述契约的前提下调整。
