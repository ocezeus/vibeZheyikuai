01核心倒计时

  • 距离下班的时:分:秒；最后 60 分钟自动切成 分:秒.厘秒（20Hz 刷新）
  • 固定班次 / 弹性工时（上班时间 + 每日时长）两种算法
  • 午休可扣除工时，下班时间按实际工时推算
  • 工作日、单双休、节假日例外、临时调休上班

02卡片

  • 收起 224×68、展开 280×188；点击展开/收起，拖拽移动，贴左 / 贴右 / 自由摆放
  • 20 秒没动自动收起（可调）；始终置顶可关；整卡透明度可调
  • 进度条 + 流动光带，最后一圈在两端淡入淡出；最后 30 分钟进度条变彩色
  • 分层窗逐像素合成：圆角、文字、图标都是抗锯齿的，小字走灰阶不镶彩边

03卡片第二行

  • 跟着一天走：距午休 → 午休中 → 距晚休 → 晚休中 → 距下班 / 马上下班
  • 收起时右侧小字显示 休 34m / 晚 1h20m
  • 午休或晚休被停用、今天不生效时，这一行自动让位，不影响另一边
  • 内置午休没填结束时间时，会拿午休时段的一条普通日程顶上（v2.9.9 修复）

04到点提醒

  • 会议、普通日程、固定日程（午休/晚休/下班/自建）到点都会提醒，提前量各自可调
  • 两种范围：只在卡片内（圆形柔光 / 进度条拉伸）或 全屏
  • 全屏三种样式：圆形柔光 / 进度条拉伸 / 警戒带（黄黑长条 + 呼吸反色 + 跑马灯）
  • 提醒常驻到时段结束；右上角 × 或点任意处关闭，同一场今天不再弹
  • 下班没打卡：常驻「该下班啦」，每 5 分钟重播，打卡后自动消失

05警戒带 → 抽屉卡

  • 触发时小卡先展开（400ms），再让黄条横贯全屏；卡片不做覆盖
  • 黄条走完、卡片收回（400ms），0.3 秒后从贴边的一侧反向拉出抽屉（550ms）
  • 抽屉是实心工业黄、和卡片同高 68 DIP、外角 14；两行字：标题 / 时间段 · 地点 · 剩余时间
  • 文字同色系三阶（暖黑 / 深褐 / 深橙），没有「会议提醒」这类标签
  • 贴左的往右拉、贴右的往左拉；一直留到日程结束，点一下收回

06日程

  • 内置三条固定日程：午休 / 晚休 / 下班，可改名、改时间、换配色、停用（不能删）
  • 自建固定日程：每天 / 单数周 / 双数周、重复到某天、开始与结束各提醒一次、39 套配色任选
  • 手动日程：日历选日期 + 15 分钟一档 + 时长 + 位置；「快速填入」3/5/15/30 分钟后、1 小时后
  • 飞书日历自动同步会议，会议与普通日程的提前量分开设置

07飞书打卡

  • 读飞书考勤对话里的上班 / 下班打卡，算迟到早退
  • 用 lark-cli 授权，设置里一键「自动找」考勤机器人会话
  • 不接飞书也能用，只按班次时间倒计时

08外观

  • 39 套内置主题（深色 / 浅色），色卡直接预览占比
  • 自建主题：只选背景色 + 进度条色，文字 / 轨道 / 对比度自动推导；可编辑、可删
  • 背景光效：原样式（默认）/ 角落柔光 A / 进度条同色光 B / A+B
  • 卡片透明度、窗口置顶、减少动态效果

09操作

  • 左键展开 / 收起；右键菜单：设置、提醒预览、窗口置顶、开机自启、退出
  • 托盘图标常驻，单击唤回；关闭设置窗不影响卡片
  • 设置支持导出 / 导入，换机一键搬家
  • 单实例运行，重复启动只把已有窗口叫出来

10适配与数据

  • 100%–300% 缩放、多显示器、4K 都按系统 DPI 渲染
  • 全屏提醒用桌面截图做底图，不依赖大尺寸分层窗（4K 下更稳）
  • 配置与日志在 %APPDATA%\WorkCountdown；便携模式：exe 旁放 portable.txt 存到同目录 data\
  • 只依赖 Windows 自带的 .NET Framework 4.x，不用装运行时
