# 上班工具箱 · UI 规格 brief（DIP）

> 用途：给另一个设计师在 HTML 里 **1:1 复刻当前界面**。
> 单位：全部为 **DIP**（= 96 DPI 下的逻辑像素，100% 缩放时 1 DIP = 1 CSS px）。源码里所有 `S(v) = round(v * scale)` 的值已按 100% 折算回 DIP；字号单位是 **pt**（`pt × 4/3 = DIP`）。
> 基线：`AppInfo.Version = "3.6.0"`（`src/Models.cs:32`）。源码位置以「文件:行号」标注，方便回查。
> 原则：源码优先于 README 和截图。README/截图与源码冲突的地方集中在第 7 节，标「待核」的是无法从源码唯一确定的值。

---

## 0. 通用约定

### 0.1 坐标系、字号换算、字体

- 悬浮卡片 / 纸条面板 / 胶囊菜单：所有几何量都经过 `S()`，**100% 下 1:1 = DIP**；150% 时整体 ×1.5（`Widget.cs:319`、`NotePanelForm.cs:241`、`BubbleMenuForm.cs:273`）。
- 设置窗口：按 96 DPI 设计，构造完成后整窗 `Scale(k, k)`（`SettingsForm.cs:161-169`）；字体按 pt 渲染，所以 150% 时框和字一起放大。
- 分层窗口（卡片 / 纸条 / 胶囊）：整帧 32 位 alpha 位图 + `UpdateLayeredWindow`，圆角靠像素 alpha，**没有系统边框、没有投影**；小字用灰阶抗锯齿（`Widget.cs:56, 349`）。

**pt → DIP（CSS px）**：

| pt | 28 | 22 | 17 | 14 | 13 | 12 | 10.5 | 9.75 | 9.5 | 9 | 8.75 | 8.625 | 8.5 | 8.25 | 7.875 | 7.5 | 7.125 | 6.75 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| DIP | 37.33 | 29.33 | 22.67 | 18.67 | 17.33 | 16 | 14 | 13 | 12.67 | 12 | 11.67 | 11.5 | 11.33 | 11 | 10.5 | 10 | 9.5 | 9 |

> 纸条面板源码里写的是「设计 px」（`F(12.5f)` 等，`NotePanelForm.cs:186-196`），换算关系是 `pt = px × 0.75`：14px = 10.5pt、12.5px = 9.375pt、11.5px = 8.625pt、10.5px = 7.875pt、10px = 7.5pt、9.5px = 7.125pt。

**字体族**（`Models.cs` 的 `UiFont`）：

| 用途 | 字体 | 备注 |
|---|---|---|
| 中文/界面文字 | `PingFang SC` → `PingFang HK/TV` → `苹方 常规` → `Noto Sans SC` → `Microsoft YaHei UI` | 可选 `fonts\` 私有字体；粗体优先用真粗体族 |
| 数字 | `Consolas`（默认） | 大号倒计时、横条数字、工资数字、`¥` 图标；设置里可改 |

### 0.2 颜色语义（全局）

主题数据来自 `ThemeDef`（`Models.cs:1831`）。各处**取色规则不一样**，这是复刻时最容易错的地方：

| 语义 | 卡片（Widget） | 纸条（NotePanel） | 右键胶囊（BubbleMenu） |
|---|---|---|---|
| 主文字 | `theme.textMain` | `theme.textMain` | `theme.textMain` |
| 次文字 | `Mix(textMain, bgBottom, 0.18)`（`MutedMix`） | `Mix(textMain, bgBottom, 0.18)` | `theme.textMuted` |
| 弱文字 | `Mix(textMain, bgBottom, 0.30)`（`DimMix`） | `Mix(textMain, bgBottom, 0.34)` | `theme.textDim` |
| 强调 | `theme.accent` | `theme.accent` | `theme.accent` |
| 成功 | `theme.success` | `theme.success` | `theme.success` |
| 渐变底 | `bgTop → bgBottom`（90°，上→下） | `Mix(bgTop,white,0.02/0.04) → bgBottom` | 同纸条（`SurfaceTop/Bottom`） |
| 轨道 | `theme.track` | — | — |
| 细边 | `accent @ 24/255`（≈9.4%），1 DIP | `accent @ 62%`，1.8 DIP | `accent`，1 DIP，透明度随状态 0.46→0.72 |
| 叠加底 | — | 深色 `white@14/255`、浅色 `black@12/255`；边框 `white@22` / `black@26` | 深色 `white@14`、浅色 `black@12`；悬停 `white@10` / `black@14` |

> **重点**：主题里的 `textMuted / textDim` 只有**右键胶囊**直接用；卡片和纸条都是从 `textMain + bgBottom` 现算的。`edge` 字段只用于纸条/胶囊的极淡描边（见 5.5）。

### 0.3 四个渲染环境

| 环境 | 底色 | 文字锚 | 圆角 | 投影 |

### 1.7 卡片外观（渐变 / 圆角 / 边框 / 光效 / 背景风格）

- **渐变**：`LinearGradientBrush(bgTop → bgBottom, 90°)`，铺满整张圆角路径（`Widget.cs:2091`）。
- **圆角**：收起 14 / 展开 18 DIP（物理像素 `S(...)`，`Widget.cs:371`）。
- **边框**：1 DIP，`Color.FromArgb(24, theme.accent)`（≈9.4% accent），沿圆角一圈（`Widget.cs:2140`）；提醒动画期间不描边。
- **卡片整体不透明度**：默认 **94%**（`frameAlpha = 240`），设置范围 30–100%，下限钳到 0.3；不是「背景透明度」，是整张卡片（含文字）的 ULW alpha（`Widget.cs:1590`）。
- **背景光效**（`PaintCardGlow`，`Widget.cs:2154-2202`，默认关）：
  - `corner` A：左上椭圆（矩形 `-0.28W,-0.35H,1.1W,1.2H`）alpha `0.30×1.6`；右下椭圆 alpha `0.15×1.6`；
  - `bar` B：中心 `(0.58W, 104/61)`、半径 `(0.60W, 0.38H)` 的椭圆，alpha `0.32×1.6`；
  - `all` A+B：两者同时叠，整体再乘 0.70（`damp`）；
  - 光色 = 当前 `accent`，静态不呼吸。
- **磨砂玻璃**（设置 `bgStyle = glass`）：用 `Frost.PaintSurface` 替代渐变——半透主题底 + 两团柔光雾 + 磨砂颗粒 + 斜向反光带 + 顶部高光/底部暗边；同一开关也作用于纸条面板和胶囊菜单。
- **卡外流光层**（独立窗口，点击穿透，四边各留 **56 DIP**）：呼吸柔光外扩 12 DIP、σ≈18、alpha 0.34→0.62/4.2s；贴边窄光 σ≈10、固定 45%；86° 锥形扫边 5.5s/圈，只露 1–2px 贴边一圈（详见 README「卡片背面的流光」）。
- **未读纸条的边框闪**（`DrawNoteRim`，`Widget.cs:3637-3652`）：沿圆角画 3 层（线宽 6/4/2 DIP，alpha = `a×24/i`）+ 2 DIP accent（alpha `a×225`）+ 1 DIP 白（alpha `a×80`）；收到纸条连闪 2 次，未读时每 5 秒沿边框轻闪。

### 5.3 提取方法（推荐，直接拿全 39 套）

```powershell
$html   = Get-Content -Raw -Encoding UTF8 design\theme-cards.html
$json   = [regex]::Match($html, 'var THEMES = (\[.*?\]);',
            [System.Text.RegularExpressions.RegexOptions]::Singleline).Groups[1].Value
$themes = $json | ConvertFrom-Json
$themes.Count                                   # 39
$themes | Select-Object id,name,accent,bgTop,bgBottom,track,textMain,textMuted,textDim,light |
    ConvertTo-Json -Depth 4                     # 直接交给 HTML 用
```

### 5.5 与 `src/Models.cs` 的交叉核对结论

已核（本 brief 编写时用脚本逐条比对）：

1. **数量 39**，id 顺序、name 与 `Models.cs` 的 `BuildAll()` 完全一致：7 条 `Make(...)`（手工值）+ 32 条 `AddTinted(...)`；
2. 经典 7 套的 `accent/success/bgTop/bgBottom/track/textMain/textMuted/textDim` 与源码**逐字节一致**；
3. 32 套中国传统色的 `bgTop/bgBottom/track/textMain/textMuted/textDim` 与源码推导公式一致（抽多套验证：`Mix(base,black,0.88/0.80/0.60)`、`Mix(base,white,0.90/0.62/0.44)`）；
4. `accent` 的推导规则：主色亮度 >0.80 → 浅色分支（HSL 目标明度 0.45，饱和 ×1.15、下限 0.22）；否则深色分支，亮度 <0.55 时 HSL 明度提到 0.52、饱和 ×1.10、下限 0.24；抽多套与 JSON 的 HSL 明度 0.52/0.45 吻合；
5. `light` 标志 = `Luminance(bgTop) > 0.56`，与 5 套浅色（ivory/bai-*）一致；
6. 若以后内置主题增删，JSON 需重生成——它只是**当前版本的渲染数据快照**，不是权威定义，权威在 `Models.cs:1916-1971`。

**必须注意的两点**：

- JSON 里的 **`edge` 是去掉 alpha 的 RGB**（`#FFFFFF` / `#182030`）。实际渲染要再乘 alpha：深色主题 `rgba(255,255,255,0.039)`、浅色主题 `rgba(24,32,48,0.118)`。直接拿 `#FFFFFF` 当 1px 边会白得刺眼。
- 卡片/纸条的「次/弱文字」不要用 JSON 里的 `textMuted/textDim`：那两列只有右键胶囊用。卡片请按 0.2 节的 `Mix(textMain,bgBottom,0.18/0.30)` 现算。

## 6. 当前真实观感（根目录真机截图）

看了 `final-collapsed.png`、`final-expanded.png`、`settings-themes.png`、`settings-note.png`、`note-drawer.png`、`note-columns.png`。
⚠ 截图版本不统一：`final-*.png` 是 150%（420×282 / 336×102），但卡片上只有 3 个图标（旧版没有 ✈ / ¥）；`settings-note.png` 标题是 **v3.2.0**（标签页还叫「固定日程」，纸条页还叫「本机 ID」）。**几何数字以源码为准，截图只用来判断观感。**

### 6.1 视觉语言总结

1. **两套设计语言并存**：悬浮卡片 / 纸条 / 胶囊菜单永远用「当前主题的深色垂直渐变 + 单一强调色」；设置窗口是独立的浅色系统（`#F6F8FB` 底、白卡、`#407CF5` 蓝），不跟主题换色。
2. **圆角大、边框极淡、不画投影**：卡片 14/18、胶囊 20（全圆角）、面板 18、白卡 10；边框要么是主题色 9%~12%，要么是 `#E6EAF2`；v3.2 起连右键气泡都不再有阴影，靠一条细边贴在桌面/卡片旁。
3. **数字是主角**：等宽 Consolas 承载 28pt 倒计时、22pt 工资、17pt 横条数字；中文说明压在 9–9.5pt；字重只有 Regular / Bold 两档，没有中间字重。
4. **一屏一个饱和色**：除状态点、进度条（含流光/彩色模式）、强调按钮外，其余全是 3 级灰阶；浅色主题会自动把整数位渐变压深、流光降亮。
5. **药丸/胶囊是主形状**：胶囊菜单、对话胶囊、昵称胶囊、发送按钮、提醒类型 chip、设置里的主题卡都是圆角矩形；只有设置页白卡、输入框用 4–12 DIP 小圆角。
6. **渐变方向统一垂直**（上→下），卡片、主题缩略图、气泡、纸条同一方向；磨砂玻璃只是把同一渐变换成半透明的雾面版本。
7. **动效短而软**：150–430ms、ease/cubic 缓动，淡入 + 轻微位移（6–14 DIP），没有弹跳；「减少动态效果」下全部跳过，只保留最终帧。
8. **边框/高光都从主题色来**：选中/悬停只改边框透明度或叠一层 10% 的同色/黑白，而不是换灰边；红绿黄等语义色只出现在状态点、提醒色块和错误提示上。
