# 主题方向稿 · 5 套整体界面皮肤

上班工具箱「整体界面重设计」的 5 个主题方向：**卡片、设置窗口、小纸条、右键胶囊**四块一起画，不是只换配色。
HTML 可交互切换，尺寸按真实 **DIP 1:1** 画（1 CSS px = 程序里 100% 缩放的 1 DIP；150% 屏就是再 ×1.5）。

## 怎么看

双击 `index.html`（Chrome / Edge）→ 顶部五个标签切换；`←` `→` 方向键也能切；底部「收起态 · 五套并排」点一下直接切过去。
直达某套：`index.html#paper`（quiet / mica / paper / instrument / neon）。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面本身（桌面场景 + 五套对比 + 说明） |
| `packs.css` | 页面骨架与四个界面的通用结构（尺寸都写在这儿） |
| `themes.css` | 5 套主题的令牌：颜色 / 字体 / 圆角 / 边框 / 阴影 / 质感 / 进度条画法 + 每套特有装饰 |
| `packs.js` | 切主题、填主题色卡、时钟；`?only=stage` 只留桌面场景 |
| `palettes.js` | 39 套内置主题的真实配色（从 `design/theme-cards.html` 的 `THEMES` JSON 提取，和 `src/Models.cs` 同源） |
| `ui-spec.md` | 现有界面（v3.6）的几何 / 字号 / 颜色 brief，实现时对照用 |
| `render.ps1` | 整页出图（默认 1.25x → `shots/final/`） |
| `compose.ps1` | 只截桌面场景 + 拼 2×3 对比图 → `shots/theme-compare.png` |
| `shots/` | 出图结果（`stage-*.png` 场景、`final/` 整页、`theme-compare.png` 对比图） |

## 五套

| # | 名字 | 一句话 | 实现成本 |
|---|---|---|---|
| 01 | 无垠 Quiet | 近黑 + 1px 细线 + 等宽数字，去掉一切装饰 | 低 |
| 02 | 云母 Mica | 半透明磨砂玻璃，桌面从卡片后面透进来（v3.6 玻璃的完整版） | 中（`Frost.cs` 已有基础） |
| 03 | 宣纸 Ink | 宣纸底 + 墨色 + 朱砂，宋体标题 + 印章，白天最舒服 | 中 |
| 04 | 仪表 Instrument | 金属壳 + 琥珀数码 + 24 格分刻进度 + 四角螺丝 | 中高 |
| 05 | 霓虹 Neon | 深空底上的品红 × 青双色霓虹，网格 + 辉光 | 高 |

## 五套共用的新结构（选中任意一套都会做）

- 设置窗口：**顶部七个标签页 → 左栏导航 + 内容卡片**（七项不变：考勤 / 固定日程 / 提醒 / 外观 / 日程 / 工资 / 纸条）。窗口画成 680×720（现在是 524×640），内容一屏更宽松。
- 卡片：收起 224×68 / 展开 280×188 不变；右上角 5 颗图标保持 `✈ ¥ ⚙ ↻ ›`；工资面板、提醒卡结构不变。
- 小纸条：抽屉式 392×282 不变（头部略高一点），气泡 / 输入框 / 昵称胶囊位置不变。
- 右键胶囊：仍是 124×40 的胶囊、6 颗、长开面板 246 宽；换的是边框、圆角与质感。
- 五套**只换皮肤**：颜色、字体、圆角、边框、阴影、质感、进度条画法、少量装饰（印章 / 螺丝 / 辉光）。布局不随主题变，所以挑完只实现一套。

## 出图

```powershell
.\design\theme-packs\render.ps1                     # 五套整页 1.25x → shots\final\
.\design\theme-packs\compose.ps1                    # 场景 + 2×3 对比图 → shots\theme-compare.png
.\design\theme-packs\render.ps1 -Theme paper -Scale 1
```

脚本保存成 **UTF-8 带 BOM**（`write` 工具会掉 BOM，PowerShell 5 按 GBK 解析中文会报「字符串缺少终止符」）。
