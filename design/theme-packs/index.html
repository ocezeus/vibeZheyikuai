五套共用同一个新结构

设置窗口从「顶部七个标签页」改成 左栏导航 + 内容卡片（考勤 / 固定日程 / 提醒 / 外观 / 日程 / 工资 / 纸条 七项不变）；卡片、小纸条、右键胶囊的布局和功能跟 v3.6 一致。五套换的是皮肤：颜色、字体、圆角、边框、质感、进度条画法和少量装饰。

怎么挑

  • 配什么壁纸：浅色壁纸 → 宣纸；照片 / 深色 → 云母、霓虹；纯黑桌面 → 无垠、仪表。
  • 想要「几乎看不见」→ 无垠；想要「有质感」→ 云母；想要「有个性」→ 仪表、霓虹。
  • 白天用得多、旁边就是飞书 → 宣纸。
