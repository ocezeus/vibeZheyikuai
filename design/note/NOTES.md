## A / C 两套面板（设置里选）

| | A · 抽屉式（默认） | C · 极简双栏 |
| --- | --- | --- |
| 尺寸 | 392×282（历史上 476） | 470×298（历史上 512） |

两套共用同一份数据、同一套动画时长和闪光逻辑，只是绘制/布局不同；在 `Widget` 里打开面板时按设置选 `NotePanelForm` 的布局。

## 贴边闪光（三选，默认①）

| 样式 | 做法 | 观感 |
| --- | --- | --- |
| **① 整圈亮边（默认）** | 沿卡片圆角路径画一圈 2px 主题色亮边 + 外发光，`rimFlash` 两次脉冲（1.15s） | 最直白：整条边亮两次，像卡片自己在呼吸 |
| ② 边框扫光 | 一段约 25% 周长的亮带沿圆角边框跑两圈 | 更「消息来了」的动感，但单帧看像整圈 |
| ③ 四角弧光 | 四个圆角/四条边各亮一段，两次脉冲 | 更轻，弱提醒 |

**大卡片、小卡片都走同一层**：`Widget` 里按卡片圆角路径画一条 2 DIP 的描边 + 外发光（不用 `CardGlowForm`，它管的是常驻流光），透明度按 `rimFlash` 曲线：0 → 0.95 → 0.12 → 0.9 → 0.1 → 0.5 → 0（两次脉冲）。未读期间每 5s 用 `rimBreath` 轻闪一次；打开小纸条 / 读完即停。

## 公共中继（已定：公共 MQTT）

本机实测三个公共 broker 都能连（CONNACK `00 00`）：`broker.hivemq.com:1883`、`test.mosquitto.org:1883`、`broker.emqx.io:1883`。默认用 **broker.hivemq.com:1883**，设置里可改地址/端口。

| 项 | 约定 |
| --- | --- |
| 主题 | 收件箱 `xzt/v1/msg/<5位ID>`（QoS0，不 retained）；在线状态 `xzt/v1/presence/<5位ID>`（retained JSON，每 30s 刷新） |
| 消息体 | `{"v":1,"from":"48372","to":"73512","text":"…","ts":1731400000}`，单条 ≤200 字 |
| 找 ID | 订阅对方 presence 主题一次（拿 retained）→ 1.5s 内收到即「在线」，超时显示「未在线」，仍允许添加 |
| 离线 | 公共 broker 不存消息：对方不在线时这条发不出去，本地提示「对方不在线，稍后再发」；不做服务端队列 |
| 存储 | 消息只存在本机 `settings.json`（每对 ID 最多 8 条），中继不落库、不做账号 |
| 隐私 | 公共 broker 明文转发；设置页明确提示「别发密码等敏感内容」；后续可再加应用层加密 |
| 实现 | 不引第三方库：`NoteRelay.cs` 里手写 MQTT 3.1.1（CONNECT/SUBSCRIBE/PUBLISH/PINGREQ），TCP 直连，断线 10s 重连 |

## 实现时落地的取舍（已按这个做）

1. **闪光样式**：默认 **① 整圈亮边**（实现里沿圆角边框画 1.5px 亮边 + 外发光，两次脉冲 1.3s；未读每 5s 呼吸）。
2. **ID 规则**：随机 5 位数（10000–99999），重装 / 重新生成会变；不做跨机唯一性校验（同 ID 概率低）。
3. **离线**：对方不在线时发送失败提示，不排队（公共中继不存档）；陌生人发来的纸条自动加一个显示 ID 的联系人。
4. **中继地址**：默认 `broker.hivemq.com:1883`，可在设置里换成自己的。
