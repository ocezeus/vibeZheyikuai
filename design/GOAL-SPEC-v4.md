## 0. 全局约定

- **画布**：卡面 280×188 DIP（`.card` L102）；CSS 按 1× 写，**1px = 1 DIP**。原点 = 卡面左上角，+x 右 / +y 下。
- **圆角**：卡 18px；`.fx` L135 亦为 18px 且 `overflow:hidden` → **卡内一切装饰被 18px 圆角裁切**。只有 `.out` 出框层（L965–968，`overflow:visible`）可画到卡外，其 SVG 视窗 `-140 -121 560 430`（1:1 对应卡坐标，负值即卡外）。舞台 560×430，卡居中于 (140,121)，四边留 140/121 DIP 出框余量。
- **循环**：`--loop:7s`（L19），**1% = 70ms**。表中「绝对时间」= 百分比×7s；带 `animation-delay:d` 的元素整条 7s 轴再后移 d（因此部分延迟元素的退场被循环点截断，由父层兜底，见下）。
- **缓动**：未标 `cubic-bezier` 者一律 CSS 默认 `ease` = cubic-bezier(.25,.1,.25,1)；`linear`、`steps()` 单独标注。
- **统一阶段**（6 版一致）：入场 0–1.6s / 停留 1.6–5.6s / 退场 5.6–6.3s；外层 `.fx` 的 `s-fx-out`（L137）在 86%→96% = **6.02–6.72s** 整体淡出兜底。生产播放按 L1748：入场 1.1–1.6s、停留 `ui.reminderHoldSeconds`（默认 6–8s）、退场 0.8s。

**卡背景（会被整层盖住）**：`.base` L119 — `#12161F`→`#1B2130` 180° + 径向 `#4C8DFF` α10%；头部行高 12、字 8.5px，绿点 4.5px `#46D39A` + 6px 辉光；数字 33px `--mono` `#EEF3FB`；副行 8.5px `#8B95A8`；进度条 left/right 16、bottom 11、高 3、`#46D39A`→`#4C8DFF`；右侧 100% 8.5px `#46D39A`（`.b-pct`）。

**遮罩层透明度的共同规律（重要）**：
- 6 版的铺底层最终都是**全不透明**：`.s1 .wash` / `.s5 .veil` / `.s6 .paper` / `.s7 .bg` / `.s8 .bg` / `.s10 .wall` 的渐变末段 α=100%（s10 的墙是 α55%+α92% 叠在不透明 `#07040A` 上）。
- alpha 时间曲线统一为：入场 **0→1**（0.21–1.40s 之间完成，各版差异在于用圆形 clip 还是上下开合，**不是**用 alpha 过渡）；停留 **1.0**（1.6–5.6s）；退场 **1→0**（6.02–6.72s，`s-fx-out` 86%→96%，ease）。
- 因此**状态栏 / 数字 / 进度条在停留期间完全不可见**：0.21s 起开始覆盖，1.19–1.40s 完全铺满；只有 0–0.21s 这一段能看到完整底图与进度条（这正是「扩散从进度条末端起」的观感来源）。
- 半透明只出现在**装饰**上：s6 四角压暗 α14%、s7 暗角 α55%、s1 柔光 α62%、s10 辉光 α34%、各版正文的投影 α12–45%。它们不是遮罩，不参与上面的曲线。

**圆角与裁剪**：卡 18px；`.fx` 18px + `overflow:hidden`；内框各自内缩（s7 inset 6/3px、s10 inset 8/1.5px、s8 inset 6/3px 圆角 13）；s6 吊牌圆角 5、内虚线圆角 3；s5/s10 的出框框体是**独立于卡圆角**的圆角矩形（s10 出框 rx34）。

**出框层的统一行为**：`.out` L965 在 8%→16% 淡入（0.56–1.12s）、80%→90% 淡出（5.60–6.30s），z-index 3，**盖在卡面之上**（会压住文字层，s8 的红圆就压在右上角）。GDI+ 必须为它扩透明边或加独立透明窗口层（HANDOFF.md L72），否则被 `WidgetForm` 裁掉。

## 实现建议

**难点排序（难 → 易）与理由**

1. **10 霓虹灯牌（最高）**：6 层文字辉光 + 双层框辉光 + 8 段离散闪烁 + 313×210 砖墙 + 8 颗尘埃；量大且都是「模糊叠加」，不做预烘会掉帧。建议整卡预合成到 1 张 280×188（+ 出框层单独 1 张）的 ARGB 位图，辉光层做成静态底图，只让「闪烁 α」和「尘埃/呼吸」动态叠加。
2. **05 星屑**：金箔渐变字要 `GraphicsPath` 取字形 + 渐变填充 + 230% 扫光；44 颗粒子 + 54 颗星 + 20px blur 星云；还有月牙遮罩与虚线轨道的 dash 动画。
3. **01 花园绽放**：图形元素最多（11 组花叶含藤 + 蝶 + 5 星点 + 6 花瓣，延迟 0.04–0.40s 共 11 档），每组长短不一的延迟与独立旋转/摇摆，路径全是贝塞尔；但都是实心填充，比辉光省。
4. **06 丝带礼物**：硬边 clip 开合 + 两级旋转（吊牌 −2.4° × 摆动 ±0.8°）+ 30 片彩屑 + 贝塞尔蝴蝶结 + 径向蜡封；难点在「旋转中的文字不抖」与纸纹对齐。
5. **07 像素（偏低）**：逻辑简单但**必须**做位图烘焙（阈值 48 + 可选膨胀 + 墨迹裁边 + 最近邻 ×2）与整数对齐；一旦是 CSS 逐帧思路就会糊。
6. **08 新粗野（最低）**：全是硬边矩形/圆/polygon + 过冲缓动 + 5 帧震屏，`SmoothingMode.None` 一把梭，无模糊无渐变（只有一条 45° 斜纹）。

**建议绘制层次（每版通用，自下而上）**

1. `.base` 底图（进度条/状态栏）——0–0.21s 完全可见，之后被逐层盖住；若为了省事可只画到 0.3s。
2. 铺底层（wash / veil / paper / bg / wall）＋ 揭示方式（s1/s5/s10 圆形 clip；s6 上下矩形对开；s7 alpha；s8 自下 clip）。
3. 装饰 A（远景/低层）：星云、星点、像素块、彩屑、飘落花瓣、扫描线、星座。
4. 装饰 B（中景）：花叶、几何块、吊牌、缎带、卡内边框、sprite、状态条。
5. **出框层 `.out`**（z-index 3，必须单独一层/扩边，s10 的柔光还要允许被舞台裁）。
6. 文字层：标题 → 分隔线/青线 → 副标题（s7 用缓存位图，s5/s10 用渐变/辉光预烘底图，s1/s8 逐字变换）。
7. 顶层压印：s8 的 3px 黑框（z-index 6）、s7 的暗角与状态条（z-index 5）、s10 的尘埃（在文字之下，z-index auto，按 DOM 顺序）。

**通用 GDI+ 注意**：模糊类一律预烘（L1750）；圆形扩散可沿用现有 `DrawCardFlood` 逐像素 mask；`PathGradientBrush` 做径向（s1 柔光、s5 星云、s10 辉光、s6 蜡封）；发光用多次叠画半透明而不是 `Glow` 类效果；所有 18px 圆角裁剪用 `GraphicsPath` + `SetClip`；逐字动画按「字索引 → 平移/旋转矩阵」在绘制时施加，不要改字符串。
